# Olive Oak Showcase

Build a premium, modern, conversion-focused website for Olive Oak Interior Decor, a Nairobi-based interior décor business specializing in curtains, blinds, window treatments, and interior décor solutions.

This is a client demo website. The finished result must look polished enough that the business owner could realistically imagine launching it as their official website.

The website should NOT look like a generic template, SaaS website, AI-generated website, or cheap local-business website. It should feel like a premium Kenyan interior décor brand with strong visual identity, excellent photography, sophisticated typography, generous whitespace, subtle animations, and a strong emphasis on beautiful interiors.
